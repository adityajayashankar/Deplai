# Code Reviewer

**Code Reviewer** appears under **Services**. It is not available in this build: there is no Code Reviewer page yet, so you cannot start a run.

When it ships, those runs will show up in **Sessions**. Until then, use **Security Agent** for SAST/SCA findings and proposed fixes, and GitHub’s own review on pull requests from **GitHub & verify**.
